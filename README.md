# Lastro — controle financeiro pessoal

![Interface do Lastro](assets/preview.png)

Abra `index.html` no navegador. Não requer servidor, conta, biblioteca ou instalação.

## Funcionalidades
- Lançamentos de entradas e saídas com data, descrição, valor e categoria.
- Edição e exclusão; saldo, receitas, despesas e participação por categoria.
- Filtro mensal ou visão de todos os períodos e exportação para CSV compatível com planilhas.
- Armazenamento `localStorage` no navegador, sem integração bancária.

Os valores são internamente armazenados em centavos inteiros para evitar erros comuns de ponto flutuante. Todas as estatísticas mostram apenas registros lançados pelo usuário; a aplicação não gera dados fictícios.
